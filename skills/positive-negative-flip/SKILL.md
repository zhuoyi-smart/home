# 正负反转

## 目标

接收一张源照片，先建立统一的复古胶片基础图，再交付且只交付以下两张最终图：

1. 常规版：复古纸艺正负形拼贴。
2. 手作版：在相同构图上加入克制的毛边、细针脚与弱针织纹理。

将基础图作为中间过程，不把它计入两张最终交付物。除非用户明确要求，否则不要添加标题、日期、文案或水印。

## 必读资源

每次执行前：

- 读取 [风格规范](references/style-guide.md)。
- 读取 [提示词模板](references/prompt-templates.md)。
- 将风格规范作为视觉边界，根据当前照片独立决定主体组、装饰母题和材质强度，不机械复制示例构图中的人物、物体、文字或装饰位置。

## 工作流

### 1. 检查源照片

使用图像查看工具检查源照片。识别唯一的“主体组”：主体本身，加上被其拿着、抱着、穿着或直接互动的物件。将手、手持物和必要服饰包含在同一抠图轮廓中，不把背景物误并入主体组。

先根据照片内容决定小型装饰母题。优先从主体、环境、动作或色彩中提取形状；只有缺少更合适的母题时才使用星星。不要把任何一张参考图的装饰位置机械复制到新照片。

### 2. 建立统一基础图

使用内置图像生成/编辑工具建立一次共享基础图，再让两个版本都基于它制作。保留身份、姿势、构图和所有关键物件。

若包含人像：

- 自然淡化痘痘、痘印、局部泛红和不均匀肤色。
- 保留毛孔、真实肤质、五官、脸型、牙齿、眼镜、发型、表情和手部结构。
- 禁止瘦脸、改鼻、放大眼睛、美白过度和塑料磨皮。

应用温和的复古富士胶片感：奶油暖高光、橄榄或鼠尾草绿阴影、轻抬黑位、柔和高光滚降、低饱和、细颗粒和轻微光晕。只让油画感出现在宽阔色彩过渡中，不把人物画成插画。

### 3. 生成常规版

以竖版 4:5 为默认画幅；若主体在该画幅中会被严重裁切，再选择更合适比例。

建立上下对应结构：

- 上半部：在暖奶油纸上放置完整主体组抠图，并保留适量留白。
- 下半部：使用源照片的背景场景，移除同一主体组，留下与上方轮廓一致的空白纸张负形。
- 将上方主体与下方空洞置于同一视觉轴线上。
- 使用窄而空白的纸张接缝连接上下两部分。
- 使用 5–9 个低对比小装饰平衡留白，不遮挡脸、手、重要文字或轮廓边缘。

保持旧纸纤维、轻微手剪毛边、柔和层间阴影和褪色印刷感。避免厚织物、粗针脚和立体手工堆叠。

### 4. 生成手作版

保持常规版的主体、正负轮廓、比例、轴线与色彩关系不变，只做克制材质升级：

- 让人物照片外沿出现极细棉纸毛边与 2–4 mm 低对比布料衬边。
- 只在局部边缘加入约 8–12 个细小断续针脚。
- 让下方空白负形仍以奶油纸为主，仅在局部加入同色、低对比的细针织压纹。
- 只允许一个微小刺绣装饰和一个微小毛毡装饰，其余使用平面旧纸元素。
- 将手作材质控制在画面信息量的约 15%，让照片与纸张占约 85%。

禁止粗毛线、厚毛毡框、整块针织填充、粗麻布、蕾丝、蝴蝶结、纽扣、亮片、大量线头或“手工材料包”效果。

### 5. 质量检查

交付前逐张确认：

- 两张图使用同一人物身份、主体组和正负形逻辑。
- 上方轮廓与下方空洞清晰对应；下方绝不出现幽灵、淡化人物或重复脸。
- 脸、牙齿、眼镜、双手、手指数量、手持物和包装文字未被重画或破坏。
- 装饰未遮挡主体信息，且与当前照片内容有关或足够克制。
- 手作版比常规版更有触感，但不能更喧闹。
- 未带入参考图或截图中的标题、日期、界面图标和水印。

若任何一项失败，只针对失败项迭代，不重写整套视觉方案。

## 工具与交付

对每个最终版本分别调用一次内置图像生成/编辑工具。明确标注每张输入图的角色，并在每次迭代中重复身份与构图不变量。

采用非覆盖式命名：

- `<源文件名>-positive-negative-regular.png`
- `<源文件名>-positive-negative-handcrafted.png`

将两张最终图保存到用户指定目录；未指定时保存到当前工作区。报告两条可点击路径、所用工具和最终提示词摘要。
