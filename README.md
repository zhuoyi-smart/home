# home

## Skills

### 正负反转

将单张照片处理为上下对应的正负形复古拼贴，每次生成两张成片：

- 常规纸艺版
- 克制手作版

Skill 文件位于 [`skills/positive-negative-flip`](skills/positive-negative-flip)。

在 Codex 中可使用 `$skill-installer` 从以下地址安装：

```text
https://github.com/zhuoyi-smart/home/tree/main/skills/positive-negative-flip
```

安装后使用 `$positive-negative-flip` 调用。

公开版本不包含任何人像参考图片，只保留工作流、风格规范和提示词模板。
